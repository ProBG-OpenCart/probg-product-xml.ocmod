# ProBG Product XML Generator 2.1.3

Версия за OpenCart 3.0.2.0 с поддръжка на множество независими XML фийдове.

## Обновяване от 1.1.0

1. Направете резервно копие на файловете и базата данни.
2. Качете ZIP файла през Extensions → Installer.
3. От Extensions → Extensions → Feeds деинсталирайте и инсталирайте отново Product XML Feed. Данните в новите таблици не се изтриват при деинсталиране.
4. Отворете настройките. Старите настройки се мигрират като фийд `all-products` при първата инсталация на 2.0.0.
5. Обновете кеша от Extensions → Modifications.

## SEO адреси

Добавете следното правило в `.htaccess` непосредствено след `RewriteBase /`:

```apache
RewriteRule ^product-feed/([a-z0-9-]+)\.xml$ index.php?route=extension/feed/product_xml&code=$1 [L,QSA]
```

Директният URL не изисква промяна в `.htaccess`:

```text
index.php?route=extension/feed/product_xml&code=all-products
```

Ако за фийда няма избрани категории, се експортират всички активни продукти. Ако има избрани категории, заявката използва `product_to_category` и `SELECT DISTINCT`, така че продуктът присъства само веднъж.

## Ново във версия 2.1.0

- Meta Title (`meta_title`)
- Meta Description (`meta_description`)
- Статус на продукта (`status`)
- Тегло (`weight`)
- Дължина (`length`)
- Ширина (`width`)
- Височина (`height`)

Всяко от тези полета може да бъде включено или изключено отделно за всеки фийд.

## Описание с HTML

Полето `<description>` се извежда в CDATA и запазва разрешената HTML структура. Ако настройката „Премахни HTML от описанието“ е активирана, описанието се преобразува в чист текст.

## Ново във версия 2.1.2

- Мета ключови думи (`meta_keyword`)
- Продуктови тагове (`tags`)

Двете полета се извеждат в CDATA и могат да се включват или изключват отделно за всеки фийд.

## Ново във версия 2.1.3

- SEO URL ключова дума на продукта (`seo_url`)

Стойността се взема от таблицата `seo_url` за текущия магазин и език. Пълният адрес продължава да се извежда отделно в полето `url`.
